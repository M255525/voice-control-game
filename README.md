# 🎤 聲控大冒險

不用手、不用鍵盤，**用你的聲音**玩遊戲！三個小遊戲練三種聲音：

- 🎈 **熱氣球飛行**（音量控制）：持續發出「啊——」，越大聲火越旺、氣球越往上，穿過烏雲和山崖之間的空隙
- 🐸 **大聲跳跳蛙**（喊一聲）：喊「嘿！」就跳，越大聲跳越高；烏鴉飛來時要安靜
- 🐤 **音階小鳥**（音高）：唱高往上、唱低往下，吃一排排飄過來的 Do Re Mi 音符（8 階依你校準的音域平均切分）

- 開始前聲音校準（環境噪音、最大聲、低音／高音），結果存在本機
- 麥克風聲音只在瀏覽器內即時算音量與音高（YIN 演算法），**不錄音、不上傳、不做語音辨識**
- 沒有麥克風可用滑鼠／觸控／空白鍵／數字鍵玩
- 結算顯示出聲秒數、最長一口氣、音域；本機排行榜；可加入主畫面（PWA）

用 `localhost` 或 HTTPS 開 `index.html`（麥克風需要安全來源）。操作說明見 `manual.html`。聲音引擎測試：`node tools/test_engine.mjs`。
